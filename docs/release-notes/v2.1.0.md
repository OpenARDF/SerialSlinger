# SerialSlinger 2.1.0

## User-visible changes

- SignalSlinger hardware failures are displayed prominently in red on Android and desktop, with the recorded failure history available until the user clears it after repair.
- Firmware updates preserve the connected unit's settings across the SignalSlinger 2.1.0 EEPROM-map migration and verify restored settings after reboot.
- After a firmware update, SerialSlinger automatically synchronizes the SignalSlinger clock unless manual time updating is enabled.

## Stability and reliability

- Temporary firmware-update backups are verified, retained only when recovery may still be needed, and removed after a successful update to conserve Android and desktop storage.
- Recovery handles legacy firmware that does not report a hardware UID, refreshes retry backups from current settings, and avoids restoring stale values over later user changes.
- Hardware-failure parsing, history handling, update-time synchronization policy, and most update recovery logic are shared by Android and desktop and covered by regression tests.

## Android release notes

Adds prominent hardware-failure warnings, protects settings during EEPROM-map firmware updates with verified recovery, and synchronizes device time after updates unless manual time mode is selected. Also improves retry safety for legacy firmware.
