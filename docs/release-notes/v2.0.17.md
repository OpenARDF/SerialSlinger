# SerialSlinger 2.0.17

## User-visible changes

- SerialSlinger reloads device settings when a connected SignalSlinger is replaced, including swaps between UID-capable and legacy no-UID firmware.
- Clone continues to support different physical units while rejecting attempts to clone the template back onto its source unit.
- Desktop users can start an explicit recovery firmware update when damaged application firmware cannot answer normal serial commands.

## Stability and reliability

- Connected-device identity probes now retry and share modern-versus-legacy comparison rules across Android and desktop.
- Desktop firmware and bootloader operations resist ordinary app termination, and firmware progress is written to the session log incrementally.
- Automatic firmware update offers are keyed to the loaded device identity so swapped units receive the appropriate update check.

## Android release notes

SerialSlinger 2.0.17 improves connected-device identity checks, reloads settings when modern and legacy SignalSlinger units are swapped, and makes automatic firmware update offers more reliable. Shared clone safeguards continue to reject the template source device.
