# SerialSlinger 2.0.19

## User-visible changes

- SerialSlinger now recognizes older SignalSlinger 1.2-series units during identity checks when they answer `INF` with command help and report version details through `VER`.
- Android and desktop now use clearer identity-check failure wording when a device identity report cannot be recognized.
- Desktop automatic device time sync now stops repeating after a failure is detected, reducing repeated background retries until the next explicit reload or successful operation.

## Stability and reliability

- Shared identity probing now falls back from `INF` to `VER` for legacy SignalSlinger firmware that predates unique-device IDs.
- Regression coverage verifies legacy `1.2s` and `1.2.1` SignalSlinger identities are recognized without treating UID-capable firmware as legacy.
- Desktop automatic-work policy coverage confirms failed automatic time sync is suppressed cleanly.

## Android release notes

SerialSlinger 2.0.19 improves compatibility with older SignalSlinger 1.2-series firmware during device identity checks and uses clearer identity-check failure messages. It also improves desktop automatic time-sync failure handling.
