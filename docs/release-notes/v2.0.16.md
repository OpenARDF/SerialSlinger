# SerialSlinger 2.0.16

## User-visible changes

- SerialSlinger detects when the connected SignalSlinger unit changes and reloads settings so cached settings are not applied to a different transmitter.
- Clone now blocks same-unit SignalSlinger clone attempts instead of letting users copy settings back onto the source unit.
- Frequency Test beacon Pattern Text is treated as fixed device-defined text rather than an editable setting.

## Stability and reliability

- SignalSlinger factory UID parsing is shared by Android and desktop identity checks before protected operations.
- Android and desktop releases now preserve safer clone behavior across swapped-device and legacy-firmware identity cases.
- The release process now records checked release notes and richer checklist evidence for future deployments.

## Android release notes

SerialSlinger 2.0.16 improves SignalSlinger clone safety by detecting connected unit changes, blocking same-unit clone attempts, and reloading settings when a different unit is attached. It also prevents Frequency Test beacon Pattern Text writes.
