# SerialSlinger 2.0.21

## User-visible changes

- Updating a connected SignalSlinger no longer replaces an existing clone template with the update target's settings. The template's source identity, schedule and edits are retained when moving between transmitters.
- On Android, reading a running SignalSlinger now offers Keep running or Stop event and read. Keeping it running or dismissing the notice does not stop the event; the stop option explicitly explains that a restart is required.
- Session history is shown only in Advanced Mode on Android and desktop. Entries use clearer outcomes, times and explanations, and the history is included in exported session logs for troubleshooting.
- Device-identification and clone messages use the full unique identifier so transmitters with identical trailing zeroes remain distinguishable.

## Stability and reliability

- Tapping or selecting displayed log text no longer records the whole document as a user action, preventing repeated log duplication and excessive file growth.
- Regression tests cover preserving clone templates across updates, explicit authorization before stopping a running event, distinct device identifiers, and log-viewer action filtering.
- Shared history parsing and presentation recognize completed events and retain diagnostic records in Android and desktop logs.
- Long serial replies are allowed to finish within a bounded extra read window, preventing the next command from corrupting the final session-history record. Silence timeouts and brief background polling are unchanged.
- Pair this app with SignalSlinger 2.0.6 to receive the firmware's manual-run sleep/wake, button handling, completion-reporting and serial reliability fixes. Updating the app alone does not replace device firmware.

## Android release notes

Firmware updates preserve your clone template. Reading a running transmitter now lets you keep it running; dismissing the notice does not stop it. Session history is clearer, appears only in Advanced Mode, and is included in logs. Viewing logs no longer duplicates their contents. Device messages show distinct full identifiers. Use SignalSlinger firmware 2.0.6 for the accompanying transmitter fixes.
