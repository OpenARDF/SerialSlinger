# SerialSlinger 2.0.23

## User-visible changes

- Android and desktop now present an explicit review-and-confirm workflow before replacing a connected SignalSlinger's settings with values from a saved clone file.
- Clone review identifies the source transmitter, preserves protected device settings, and clearly distinguishes settings that will change from settings that will remain untouched.
- Session logs retain a reliable device identity, and Android's header and version presentation are clearer during device work and testing.

## Stability and reliability

- Android and desktop share the same clone-workflow presentation and session-log identity rules, with platform-specific UI kept intentionally native.
- Build, test, lint, installed-package smoke, dependency-update, and release-publication checks are more comprehensive and reproducible across macOS, Linux, Windows, and Android, including a feasible and tightly scoped tag-source guard.
- New shared, Android, desktop, release-script, and installed-package tests cover the added behavior and packaging safeguards.

## Android release notes

Adds a clear review step before replacing a SignalSlinger's settings from a clone file, identifies the source transmitter, and preserves protected settings. Improves session-log identity and the Android header/version display. Includes broader reliability and release checks.
