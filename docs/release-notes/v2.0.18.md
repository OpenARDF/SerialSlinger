# SerialSlinger 2.0.18

## User-visible changes

- Android and desktop now show whether thermal shutdown is enabled or disabled on SignalSlinger firmware 2.0.4 and newer.
- Both apps can explicitly disable thermal shutdown or enable it at a threshold from 30 to 85 C. Fan control and temperature logging remain active while thermal shutdown is disabled.
- Automatic device clock synchronization now detects large clock discrepancies even when rapid samples do not cross a one-second boundary.

## Stability and reliability

- Shared capability detection, response parsing, and verified command readback keep Android and desktop thermal-shutdown behavior aligned.
- Arducon retains its existing 30 to 60 C threshold behavior without the SignalSlinger-specific enable/disable mode.
- Firmware-cache regression coverage confirms that a newer resident SignalSlinger firmware update remains preferred when the online release is older or unavailable.

## Android release notes

SerialSlinger 2.0.18 adds explicit thermal-shutdown controls for SignalSlinger 2.0.4+, including Disabled and Enabled-at-threshold choices from 30 to 85 C. Fan control and temperature logging remain active while shutdown is disabled. It also improves automatic device-clock synchronization.
