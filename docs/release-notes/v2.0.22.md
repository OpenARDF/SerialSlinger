# SerialSlinger 2.0.22

## User-visible changes

- SignalSlinger RF frequency calibration is now displayed on Android and desktop after device readback, including echoed calibration responses.
- Available firmware updates remain visible when the matching update package is already resident on the device, so an interrupted or deferred update can still be resumed.
- Desktop device-transition dialogs now close when their state becomes stale, and startup focus stays off editable settings to prevent accidental changes while a device loads.

## Stability and reliability

- RF calibration remains attached to the loaded transmitter when later identity readback arrives without repeating the calibration field.
- Shared protocol, session-workflow, firmware-offer, and release-cache tests cover RF calibration parsing and preservation plus resident-update selection.
- Android and desktop use the same shared calibration and firmware-update state; the desktop-only focus and dialog changes address native desktop window behavior.

## Android release notes

Shows SignalSlinger RF frequency calibration after device readback and recognizes echoed calibration responses. Resident firmware updates remain available to resume. RF calibration now stays associated with the loaded transmitter when later identity data omits it. Includes shared reliability and update-selection fixes.
