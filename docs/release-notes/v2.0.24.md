# SerialSlinger 2.0.24

## User-visible changes

- Android uses refreshed USB serial and system libraries for compatibility with current devices and Android releases.
- Android round launcher icons now use the intended SerialSlinger artwork at every density.
- Android interface text is consistently sourced from application resources, improving presentation and localization readiness without changing established workflows.

## Stability and reliability

- Android release bundles are now built with the configured Play upload key and verified against the expected upload-certificate fingerprint.
- Physical-device instrumentation, attached-SignalSlinger regression with settings restoration, and Android 15 16 KB page-size checks are enforced as explicit release evidence.
- The build uses the mutually compatible Gradle 9.6, Android Gradle Plugin 9.4.1, Kotlin 2.4.20, AndroidX Core 1.19.1, and USB serial 3.11.0 toolchain, with zero-vulnerability dependency and static-analysis gates.

## Android release notes

Refreshes Android USB serial and system compatibility, corrects round launcher icons, and improves text/resource handling. Adds verified Play upload signing, physical-device instrumentation, 16 KB page-size checks, and safer attached-SignalSlinger regression with settings restoration.
